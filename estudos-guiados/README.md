# Estudos guiados

Os estudos guiados organizam uma sequência de revisão e consolidação para cada aula/capítulo da disciplina.

Eles não substituem os slides, as notas ou as listas. A proposta é conectar esses materiais em um roteiro de estudo ativo:

1. identificar o que precisa ser compreendido;
2. revisar os conceitos essenciais;
3. responder perguntas de verificação sem consultar o material;
4. aplicar os conceitos em pequenos problemas;
5. utilizar atividades e visualizações quando disponíveis;
6. concluir com uma autoavaliação.
