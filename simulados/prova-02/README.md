- [Simulado 01](simulado-01.md)

## Conteúdos

Lógica proposicional, lógica de primeira ordem, inferência, unificação, Prolog, Árvores de Decisão, KNN, SVM, PCA, avaliação experimental e Algoritmos Genéticos.

## Orientações

Resolva inicialmente sem consulta e registre tanto os cálculos quanto as justificativas. Os três simulados cobrem o mesmo escopo, com problemas e dados distintos. Depois, retome as aulas, notas visuais e estudos guiados nos pontos em que encontrou dificuldades. Enunciados de treino não antecipam a prova oficial; gabaritos não são disponibilizados.
