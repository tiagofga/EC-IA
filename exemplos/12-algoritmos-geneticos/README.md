# Exemplos Python - Aula 12: Algoritmos Genéticos

`ag_imagem_4x4.py` é uma **solução de referência após a aula** para a imagem binária 4 × 4, com torneio, crossover de um ponto, mutação por bit e elitismo. Utiliza `random.Random(seed)` para reprodução das execuções.

Execute:

```bash
python ag_imagem_4x4.py --seed 42 --testes --sem-grafico
python ag_imagem_4x4.py --seed 42 --mutacao 0.20
```

Python 3.10+; `matplotlib` é opcional para gerar o gráfico (`python -m pip install matplotlib`).
