# Exemplos públicos de Inteligência Artificial

Exemplos de aprendizagem supervisionada (Aulas 08 a 11), computação natural (Aulas 12 a 14) e ensembles (Aula 15). As dependências variam conforme a aula; consulte o README de cada exemplo. Para AG e Enxames, `matplotlib` é opcional; NSA e CLONALG não exigem bibliotecas externas. Não é exigido criar `venv`.

Os códigos e as orientações também podem ser consultados na [página de Exemplos Python](https://tiagofga.github.io/EC-IA/exemplos/).
