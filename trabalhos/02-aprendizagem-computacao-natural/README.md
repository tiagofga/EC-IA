# Trabalho 02 - Aprendizado de Máquina e Computação Natural

**Semestre:** 2026/2  
**Entrega:** 03/12/2026, via SIGAA  
**Valor:** 20,0 pontos

O enunciado oficial em PDF estabelece todos os requisitos, critérios e procedimentos de entrega. Este README é um guia de navegação, não um substituto do documento oficial.

## Parte 1 - Aprendizado supervisionado (8,0 pontos)

Escolher e justificar uma base real do UCI Machine Learning Repository ou do Kaggle. Comparar os cinco modelos obrigatórios sob o mesmo protocolo:

- Árvore de Decisão;
- K-Nearest Neighbors (KNN);
- Support Vector Machines (SVM);
- Random Forest;
- AdaBoost.

Documentar análise exploratória, pré-processamento sem vazamento de dados, validação cruzada, métricas e comparação crítica dos resultados. É permitido utilizar `scikit-learn` nessa parte.

## Parte 2 - Computação Natural (8,0 pontos)

Escolher **um único problema** dentre os 50 temas do Apêndice A do enunciado. Implementar, pelo próprio grupo:

- Algoritmo Genético (AG);
- PSO ou ACO (Inteligência de Enxame);
- CLONALG, ou alternativa imune previamente aprovada.

Os três métodos devem usar a mesma formulação do problema, as mesmas instâncias e a mesma função objetivo. Comparar a qualidade, a viabilidade e o esforço computacional em pelo menos 10 execuções independentes por método e instância.

## Parte 3 - Documentação e entrega (4,0 pontos)

Apresentar relatório técnico de 6 a 10 páginas de conteúdo principal, repositório Git público reprodutível, documentação das dependências e das sementes, tabelas e gráficos. Registrar no repositório do grupo a tag `v1.0-submissao`.
