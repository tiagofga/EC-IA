# Visualização - Resolução Proposicional

Esta visualização acompanha uma prova por **resolução e refutação** passo a passo.

## Etapas mostradas

1. apresentar a base de conhecimento e a consulta;
2. adicionar a negação da consulta;
3. trabalhar com cláusulas em Forma Normal Conjuntiva (FNC);
4. selecionar cláusulas com literais complementares;
5. gerar resolventes;
6. verificar se surge a cláusula vazia `□`.

## O que observar

- a resolução opera sobre cláusulas;
- o sucesso da refutação é indicado pela cláusula vazia;
- cada resolvente elimina um par de literais complementares;
- quando não há cláusula vazia, a execução pode estabilizar sem provar a consulta.
