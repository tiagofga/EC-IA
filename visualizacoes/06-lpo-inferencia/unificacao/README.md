# Visualização - Unificação em LPO

Esta visualização mostra a construção passo a passo de uma substituição.

## O que observar

- predicado e aridade;
- comparação argumento a argumento;
- associação de variáveis;
- propagação da substituição;
- sucesso ou falha;
- MGU resultante quando existir.

A interface utiliza exemplos predefinidos para permitir comparação direta entre casos de sucesso e falha.
