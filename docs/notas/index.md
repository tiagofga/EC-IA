# Notas complementares

As notas complementares organizam pontos de revisão que não precisam repetir integralmente os slides. Elas funcionam como apoio entre a aula, o estudo guiado e as atividades.

## Como usar

Use as notas para:

- revisar conceitos específicos após a aula;
- complementar o estudo guiado;
- comparar definições e propriedades;
- registrar conexões entre conteúdos de aulas diferentes.

As notas são materiais de apoio e não substituem os slides, as atividades ou as explicações realizadas em sala.
