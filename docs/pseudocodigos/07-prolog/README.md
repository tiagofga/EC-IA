# Aula 07 - Pseudocódigos conceituais de Prolog

Esta seção descreve os mecanismos operacionais usados para compreender a execução de programas Prolog. Os textos são conceituais e não substituem a sintaxe real da linguagem.

## Conteúdo

- [Resolução de metas](resolucao-de-metas.md)
- [Retrocesso e busca de alternativas](retrocesso-e-alternativas.md)
- [Recursão e relações transitivas](recursao.md)
- [Listas recursivas](listas-recursivas.md)
- [Negação por falha](negacao-por-falha.md)

## Relação com as aulas anteriores

- a **unificação** vem da Aula 06;
- a **resolução de metas** corresponde a uma exploração orientada pela consulta;
- o **retrocesso** retorna ao último ponto de escolha;
- a exploração operacional possui relação direta com **Busca em Profundidade**.

Use estes pseudocódigos junto com a nota visual, o estudo guiado e a visualização da Aula 07.
