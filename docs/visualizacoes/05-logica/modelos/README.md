# Visualização - Modelos e Consequência Lógica

Esta visualização torna visíveis os conceitos de **mundo possível**, **modelo**, **satisfatibilidade** e **consequência lógica** estudados na Aula 05.

## O que observar

- cada linha representa uma interpretação para os símbolos proposicionais;
- uma linha é modelo da KB quando satisfaz todas as sentenças da base;
- `KB ⊨ α` somente quando `α` é verdadeira em **todos** os modelos da KB;
- um único modelo da KB em que `α` seja falsa funciona como contraexemplo;
- fórmulas válidas são verdadeiras em todos os modelos;
- fórmulas insatisfatíveis não são verdadeiras em nenhum modelo.

A interface oferece exemplos predefinidos e permite avançar entre os mundos possíveis para acompanhar a avaliação.
