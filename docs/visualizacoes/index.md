# Visualizações

A Aula 04 possui visualizações didáticas baseadas em traces pré-calculados.

## Métodos disponíveis

### Busca não informada

- Busca em Largura - BFS
- Busca em Profundidade - DFS
- Busca de Custo Uniforme - UCS

### Busca informada

- Busca Gulosa - Greedy Search
- A*
- Beam Search

### Busca local e otimização

- Hill Climbing
- Simulated Annealing
- Algoritmo Genético - AG
