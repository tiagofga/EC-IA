# Laboratório integrado de otimização - AG, ACO, BPSO e CLONALG

Compare os quatro métodos no mesmo alvo binário 4 × 4, com fitness igual ao número de bits corretos (0 a 16). Configure a semente, população e orçamento comum de avaliações; os parâmetros específicos aparecem conforme o método escolhido.

Acompanhe os estados internos e a convergência por avaliações. Todas as execuções consomem o orçamento configurado, inclusive a avaliação inicial e uma última etapa parcial quando necessário. O gráfico usa a mesma escala horizontal para todos os métodos. A comparação de uma única semente é ilustrativa; para conclusões experimentais, repita com várias sementes.

O CLONALG apresenta ranking, afinidade, clonagem, hipermutação e renovação. A variante segue o laboratório imunológico, mas não interrompe ao atingir o ótimo, para manter o orçamento comum.
