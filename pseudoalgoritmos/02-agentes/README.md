# Pseudocódigos - Aula 02: Agentes Inteligentes

Esta pasta reúne os pseudocódigos que aparecem conceitualmente nos slides da Aula 02.

| Estrutura | Ideia central |
|---|---|
| Agente baseado em tabela | usa a sequência perceptiva completa para consultar uma ação |
| Agente reativo simples | escolhe uma regra a partir da percepção/estado corrente |
| Agente reativo baseado em modelo | atualiza um estado interno antes de selecionar a regra |

Os slides também apresentam agentes orientados por metas, agentes orientados por utilidade e agentes de aprendizagem, mas nesses casos o material utiliza diagramas de arquitetura conceitual, não pseudocódigos. Por isso eles não são transformados artificialmente em algoritmos nesta seção.
