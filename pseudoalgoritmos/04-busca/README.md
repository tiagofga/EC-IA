# Pseudocódigos - Aula 04

Material conceitual, independente de linguagem de programação.

| Estratégia | Regra de seleção |
|---|---|
| BFS | menor profundidade / FIFO |
| DFS | maior profundidade / LIFO |
| Custo Uniforme | menor `g(n)` |
| Busca Gulosa | menor `h(n)` |
| A* | menor `f(n) = g(n) + h(n)` |

Os pseudocódigos não constituem uma implementação pronta para o Trabalho 1.
