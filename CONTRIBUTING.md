# Contribuição e histórico

## Commits

Todo commit deve seguir o padrão Conventional Commits:

```text
<tipo>(<escopo>): <descrição>
```

Tipos preferenciais neste repositório:

- `feat`: nova funcionalidade ou visualização;
- `fix`: correção de conteúdo executável ou navegação;
- `content`: inclusão ou atualização de material didático;
- `docs`: documentação do repositório;
- `refactor`: reorganização sem alteração do conteúdo pedagógico;
- `chore`: manutenção, configuração e releases.

Exemplos:

```text
content(aula-04): add informed search slides
content(lista-04): add search strategies exercises
feat(busca): add trace-based search visualization
docs(plano): add 2026-2 didactic plan
chore(release): prepare v0.1.0
```

## Conteúdo público

Não adicionar fontes `.tex`, gabaritos, soluções ainda não liberadas, testes ocultos ou outros materiais internos do docente.
